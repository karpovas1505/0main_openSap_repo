# Обзор файлов проекта ABAP Package Explorer

## Основные программы

### ZPP_PACKAGE_EXPLORER.abap
- **Описание**: Базовая версия программы исследования пакетов
- **Функции**: 
  - Простое дерево объектов пакета
  - Двойной клик для редактирования
  - Отображение основной информации
- **Экран**: 9000
- **Размер**: ~400 строк кода

### ZPP_PACKAGE_EXPLORER_ADVANCED.abap
- **Описание**: Расширенная версия с дополнительными возможностями
- **Функции**:
  - Иерархическое дерево с группировкой
  - Контекстное меню
  - Поиск и фильтрация
  - Тулбар с кнопками
  - Обработка событий
- **Экран**: 9001
- **Размер**: ~800+ строк кода

## Вспомогательные файлы

### ZPP_PACKAGE_EXPLORER_DESCRIPTIONS.abap
- **Описание**: Include с функциями получения описаний объектов
- **Функции**:
  - Получение описаний программ, классов, таблиц
  - Поддержка множества типов объектов
  - Универсальное использование в обеих программах
- **Размер**: ~300 строк кода

### ZPP_PACKAGE_EXPLORER.screen.9000
- **Описание**: Определение экрана 9000 для базовой версии
- **Содержимое**:
  - Flow Logic для экрана
  - Описание Custom Container
  - Комментарии по размещению элементов

### ZPP_PACKAGE_EXPLORER.texts
- **Описание**: Текстовые элементы для программы
- **Содержимое**:
  - Заголовки селекционного экрана
  - Описания GUI Status и Title
  - Комментарии по настройке интерфейса

## Зависимости между файлами

### Базовая версия
```
ZPP_PACKAGE_EXPLORER.abap
├── INCLUDE ZPP_PACKAGE_EXPLORER_DESCRIPTIONS
├── CALL SCREEN 9000
├── SET PF-STATUS 'MAIN'
└── SET TITLEBAR 'TITLE'
```

### Расширенная версия
```
ZPP_PACKAGE_EXPLORER_ADVANCED.abap
├── INCLUDE ZPP_PACKAGE_EXPLORER_DESCRIPTIONS
├── CALL SCREEN 9001
├── SET PF-STATUS 'MAIN_ADVANCED'
└── SET TITLEBAR 'TITLE_ADVANCED'
```

## Установка в правильном порядке

1. **ZPP_PACKAGE_EXPLORER_DESCRIPTIONS.abap** (сначала include)
2. **ZPP_PACKAGE_EXPLORER.abap** (базовая программа)
3. **ZPP_PACKAGE_EXPLORER_ADVANCED.abap** (расширенная программа)
4. **Экраны** (9000, 9001)
5. **GUI Status и Title**
6. **Текстовые элементы**

## Размеры файлов
