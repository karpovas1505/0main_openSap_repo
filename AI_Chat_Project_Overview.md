# ABAP ИИ Чат - Обзор проекта

## 🎯 Цель проекта

Создание полноценного интерфейса для общения с искусственным интеллектом прямо из системы SAP. Программа позволяет разработчикам, консультантам и другим специалистам использовать мощь ИИ для решения рабочих задач.

## 📦 Состав проекта

### 🚀 Основные файлы

#### 1. **sap_ai_chat.abap** - Главная программа
- **Размер**: ~500 строк кода
- **Функции**: Полноценный чат с OpenAI API
- **Особенности**:
  - Современный HTML интерфейс
  - Обработка событий в реальном времени
  - Красивый дизайн с цветовой схемой
  - Поддержка системных промптов
  - Валидация и обработка ошибок

#### 2. **multi_ai_chat.abap** - Расширенная версия
- **Размер**: ~800 строк кода
- **Функции**: Мультипровайдерный чат
- **Особенности**:
  - Поддержка OpenAI, Claude, Gemini
  - Система сессий с уникальными ID
  - Гибкая архитектура классов
  - Продвинутые настройки конфигурации

#### 3. **ai_chat_prompts_config.abap** - Конфигурация
- **Размер**: ~300 строк кода
- **Функции**: Настройки и шаблоны
- **Особенности**:
  - 10 готовых системных промптов
  - Быстрые команды для частых задач
  - Конфигурация для разных ролей
  - Управление командами чата

#### 4. **ai_chat_screen.abap** - Описание экрана
- **Размер**: ~50 строк комментариев
- **Функции**: Инструкции по созданию UI
- **Особенности**:
  - Подробные инструкции Screen Painter
  - Настройка GUI статусов
  - Горячие клавиши

#### 5. **README_AI_Chat.md** - Документация
- **Размер**: ~500 строк документации
- **Функции**: Полное руководство
- **Особенности**:
  - Пошаговая установка
  - Примеры использования
  - Конфигурация API провайдеров
  - Решение проблем

## 🏗️ Архитектура решения

### Компоненты системы

```
┌─────────────────────────────────────────────────────────────┐
│                    ABAP ИИ Чат Система                     │
├─────────────────────────────────────────────────────────────┤
│  Пользовательский интерфейс (HTML + Text Editor)           │
│  ├─ HTML Viewer (История чата)                             │
│  ├─ Text Editor (Ввод сообщений)                           │
│  └─ Toolbar (Команды управления)                           │
├─────────────────────────────────────────────────────────────┤
│  Бизнес-логика (ABAP Classes)                              │
│  ├─ lcl_ai_client (Основной клиент)                       │
│  ├─ lcl_ai_manager (Менеджер провайдеров)                 │
│  ├─ lcl_chat_ui (Интерфейс чата)                          │
│  └─ lcl_prompt_manager (Управление промптами)             │
├─────────────────────────────────────────────────────────────┤
│  Интеграционный слой (HTTP Client)                         │
│  ├─ OpenAI API                                             │
│  ├─ Claude API                                             │
│  ├─ Gemini API                                             │
│  └─ Local API                                              │
├─────────────────────────────────────────────────────────────┤
│  Слой данных (Memory Tables)                               │
│  ├─ Сессии чата                                            │
│  ├─ История сообщений                                      │
│  ├─ Конфигурация провайдеров                               │
│  └─ Пользовательские настройки                             │
└─────────────────────────────────────────────────────────────┘
```

### Поток данных

1. **Пользователь** вводит сообщение
2. **UI слой** обрабатывает событие
3. **Бизнес-логика** валидирует и обрабатывает
4. **HTTP клиент** отправляет запрос к API
5. **API** возвращает ответ
6. **JSON парсер** извлекает содержимое
7. **UI обновляется** с новым сообщением

- **Цветовая схема**: Синий (пользователь) / Серый (ИИ)

- **Аудит**: Логирование всех запросов

## 📊 Поддерживаемые провайдеры

### OpenAI ✅
- **Модели**: GPT-3.5 Turbo, GPT-4, GPT-4 Turbo
- **Особенности**: Стриминг, большой контекст
- **Стоимость**: $0.002/1K токенов

### Claude ⭕ (В разработке)
- **Модели**: Claude 3 Sonnet, Opus, Haiku
- **Особенности**: Длинный контекст (100K токенов)
- **Стоимость**: $0.015/1K токенов

### Gemini ⭕ (В разработке)
- **Модели**: Gemini Pro, Gemini Pro Vision
- **Особенности**: Мультимодальность
- **Стоимость**: $0.001/1K токенов

### Локальные API ⭕ (В разработке)
- **Модели**: Ollama, LM Studio
- **Особенности**: Приватность, бесплатность
- **Стоимость**: Бесплатно
