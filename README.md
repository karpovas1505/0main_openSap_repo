# ABAP Package Explorer - Исследователь пакетов разработки

Набор программ для исследования пакетов разработки в SAP системе с возможностью визуализации в виде дерева и быстрого редактирования объектов.

## Описание

Данный проект содержит две версии программы для исследования пакетов разработки:

### 1. Базовая версия (ZPP_PACKAGE_EXPLORER)
- Простое дерево объектов пакета
- Возможность редактирования объектов двойным кликом
- Отображение основной информации об объектах

### 2. Расширенная версия (ZPP_PACKAGE_EXPLORER_ADVANCED)
- Иерархическое дерево с группировкой по типам объектов
- Контекстное меню с дополнительными функциями
- Поиск и фильтрация объектов
- Тулбар с кнопками быстрого доступа
- Расширенные возможности навигации

## Поддерживаемые типы объектов

- **PROG** - Программы (Reports)
- **CLAS** - Классы
- **FUGR** - Группы функций
- **TABL** - Таблицы
- **DTEL** - Элементы данных
- **DOMA** - Домены
- **TRAN** - Транзакции
- **MSAG** - Классы сообщений
- **VIEW** - Представления
- **INTF** - Интерфейсы
- **WDYA** - Web Dynpro приложения
- **WAPA** - BSP приложения
- **ENHO** - Улучшения (Enhancements)
- **AUTH** - Объекты авторизации
- И другие типы объектов

## Установка

### Шаг 1: Создание программ

1. Создайте report **ZPP_PACKAGE_EXPLORER** в SE80/SE38
2. Скопируйте код из файла `ZPP_PACKAGE_EXPLORER.abap`
3. Создайте report **ZPP_PACKAGE_EXPLORER_ADVANCED** для расширенной версии
4. Скопируйте код из файла `ZPP_PACKAGE_EXPLORER_ADVANCED.abap`

### Шаг 2: Создание Include

1. Создайте include **ZPP_PACKAGE_EXPLORER_DESCRIPTIONS**
2. Скопируйте код из файла `ZPP_PACKAGE_EXPLORER_DESCRIPTIONS.abap`
3. Добавьте этот include в обе программы

### Шаг 3: Создание экранов

#### Для базовой версии (экран 9000):
```
- Создайте экран 9000 в SE80
- Добавьте Custom Container с именем 'CONTAINER'
- Разместите его на весь экран
- Скопируйте flow logic из файла ZPP_PACKAGE_EXPLORER.screen.9000
```

#### Для расширенной версии (экран 9001):
```
- Создайте экран 9001 в SE80
- Добавьте Custom Container с именем 'CONTAINER' (основной)
- Добавьте Custom Container с именем 'TOOLBAR' (тулбар)
- Добавьте Custom Container с именем 'SEARCH' (поиск)
- Настройте размеры и расположение контейнеров
```

### Шаг 4: Создание GUI Status и Title

#### GUI Status:
```
- Создайте GUI Status 'MAIN' для базовой версии
- Создайте GUI Status 'MAIN_ADVANCED' для расширенной версии
- Добавьте стандартные кнопки: BACK, EXIT, CANC
- Добавьте кнопку REFRESH для обновления дерева
```

#### Title:
```
- Создайте Title 'TITLE' с текстом "Исследователь пакетов разработки"
- Создайте Title 'TITLE_ADVANCED' с текстом "Расширенный исследователь пакетов"
```

### Шаг 5: Текстовые элементы

Добавьте текстовые элементы согласно файлу `ZPP_PACKAGE_EXPLORER.texts`:

```
TEXT-001: Параметры выбора
TEXT-002: Фильтр по типам объектов
TEXT-003: Поиск объектов
```

## Использование

### Базовая версия

1. Запустите программу **ZPP_PACKAGE_EXPLORER**
2. Введите имя пакета разработки
3. Нажмите F8 для выполнения
4. В открывшемся дереве:
   - Двойной клик по объекту для редактирования
   - F5 для обновления дерева
   - F3/F12/F15 для выхода

### Расширенная версия

1. Запустите программу **ZPP_PACKAGE_EXPLORER_ADVANCED**
2. Настройте параметры:
   - Введите имя пакета разработки
   - Выберите типы объектов для отображения
   - Введите строку поиска (опционально)
3. Нажмите F8 для выполнения
4. В открывшемся интерфейсе:
   - Используйте тулбар для быстрого доступа к функциям
   - Двойной клик по объекту для редактирования
   - Правый клик для контекстного меню
   - Кнопки развернуть/свернуть все узлы

## Функциональность

### Контекстное меню (расширенная версия)

- **Редактировать** - Открыть объект для редактирования
- **Просмотр** - Открыть объект только для просмотра
- **Копировать имя** - Скопировать имя объекта
- **Где используется** - Показать анализ использования объекта

### Тулбар (расширенная версия)

- **Обновить** - Обновить дерево объектов
- **Поиск** - Открыть диалог поиска
- **Развернуть все** - Развернуть все узлы дерева
- **Свернуть все** - Свернуть все узлы дерева
- **Фильтр** - Настройка фильтров

### Поиск и фильтрация

- Фильтрация по типам объектов на селекционном экране
- Поиск по имени объекта или описанию
- Динамический поиск через тулбар

## Требования к системе

- SAP NetWeaver 7.0 или выше
- Права доступа к таблицам:
  - TADIR (репозиторий объектов)
  - TDEVC (пакеты разработки)
  - TRDIRT (заголовки программ)
  - SEOCLASS (классы)
  - TLIBG (группы функций)
  - DD02T, DD04T, DD01T (словарь данных)
  - TSTCT (транзакции)
  - И другие системные таблицы

## Права доступа

Для полноценной работы программы требуются права на:
- Чтение системных таблиц
- Запуск транзакций SE80, SE11, SE93
- Выполнение функций поиска и анализа

## Расширение функциональности

Программа легко расширяется для поддержки новых типов объектов:

1. Добавьте новый тип в процедуру `set_object_icon_and_description`
2. Создайте новую процедуру получения описания в include
3. Добавьте обработку в процедуру `edit_object`
4. Обновите фильтры на селекционном экране


## Устранение неполадок

### Ошибка "Пакет не найден"
- Проверьте правильность имени пакета
- Убедитесь в наличии прав доступа к таблице TDEVC

### Пустое дерево
- Проверьте фильтры на селекционном экране
- Убедитесь, что в пакете есть объекты выбранных типов

### Ошибки при редактировании
- Проверьте права доступа к транзакциям SE80, SE11, SE93
- Убедитесь в правильности параметров SPA/GPA

## Поддержка

Для получения помощи или сообщения об ошибках:
1. Проверьте системные логи (SM21)
2. Проверьте права доступа пользователя
3. Убедитесь в корректности установки всех компонентов
