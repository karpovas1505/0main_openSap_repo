# ABAP Программа для работы с сбытовыми фактурами

## Описание
Программа **ZSD_INVOICE_EDIT** предназначена для выбора, отображения и редактирования сбытовых фактур в системе SAP с использованием ALV Grid с возможностью редактирования.

## Функциональность

### 🔍 Селекционный экран
- **Номер фактуры** (s_vbeln) - выбор по номеру документа биллинга
- **Дата фактуры** (s_fkdat) - выбор по дате выставления (по умолчанию последние 30 дней)
- **Плательщик** (s_kunag) - выбор по коду клиента
- **Сбытовая организация** (s_vkorg) - фильтр по сбытовой организации
- **Канал сбыта** (s_vtweg) - фильтр по каналу сбыта
- **Область сбыта** (s_spart) - фильтр по области сбыта
- **Тип документа** (s_fkart) - фильтр по типу документа биллинга

### ⚙️ Настройки отображения
- **Разрешить редактирование** (p_edit) - включает/отключает возможность редактирования в ALV
- **Разрешить сохранение** (p_save) - показывает/скрывает кнопку сохранения

### 📊 Отображаемые данные
- **Номер фактуры** (VBELN) - ключевое поле, не редактируется
- **Дата фактуры** (FKDAT) - редактируется
- **Плательщик** (KUNAG) - редактируется с проверкой существования клиента
- **Наименование клиента** (NAME1) - только для просмотра
- **Сумма** (NETWR) - редактируется с проверкой на отрицательные значения
- **Валюта** (WAERK) - редактируется
- **Сбытовая организация** (VKORG) - редактируется
- **Канал сбыта** (VTWEG) - редактируется
- **Область сбыта** (SPART) - редактируется
- **Тип документа** (FKART) - редактируется

## 🎨 Визуальные особенности

### Цветовая схема
- **Красный цвет** - отмененные документы (FKSTO = 'X')
- **Желтый цвет** - документы с нулевой суммой (NETWR = 0)
- **Зебра-раскраска** - для лучшего восприятия данных

### Дополнительные функции
- **Сумма по колонкам** - автоматический подсчет итогов по сумме
- **Оптимизация ширины** - автоматическая настройка ширины колонок
- **Сохранение вариантов** - возможность сохранять пользовательские настройки

## 🔧 Технические особенности

### Используемые таблицы
- **VBRK** - заголовки документов биллинга
- **KNA1** - основные данные клиентов

### Валидация данных
- Проверка существования клиента при изменении поля KUNAG
- Проверка корректности суммы (не может быть отрицательной)
- Проверка даты (не может быть больше текущей)

### События ALV
- **DATA_CHANGED** - обработка изменения данных с валидацией
- **TOOLBAR** - добавление пользовательских кнопок
- **USER_COMMAND** - обработка пользовательских команд

## 📋 Инструкция по использованию

### 1. Запуск программы
```abap
SE38 -> ZSD_INVOICE_EDIT -> Execute (F8)
```

### 2. Заполнение селекционного экрана
- Укажите хотя бы один параметр отбора
- По умолчанию установлен период за последние 30 дней
- Отметьте нужные чекбоксы для редактирования и сохранения

### 3. Работа с ALV Grid
- Дважды кликните на ячейку для редактирования
- Используйте Tab для перехода между полями
- Нажмите Enter для подтверждения изменений

### 4. Сохранение изменений
- Нажмите кнопку "Сохранить" на панели инструментов
- Подтвердите действие в диалоговом окне

### 5. Экспорт данных
- Нажмите кнопку "Экспорт" для выгрузки в Excel
- Выберите нужные опции экспорта

## 📝 Примечания

### Авторизация
Для работы с программой требуются следующие авторизации:
- **S_TCODE** - доступ к транзакции
- **V_VBRK_VKO** - доступ к документам биллинга
- **F_KNA1_BEK** - доступ к данным клиентов

### Производительность
- Программа оптимизирована для работы с большими объемами данных
- Используется LEFT JOIN для получения наименований клиентов
- Исключены отмененные документы для повышения производительности

### Совместимость
- Программа совместима с SAP ECC 6.0 и выше
- Поддерживает Unicode
- Совместима с SAP S/4HANA

## 🐛 Известные ограничения

1. **Сохранение изменений** - в текущей версии реализовано только отображение сообщения
2. **Массовое редактирование** - нет возможности редактирования нескольких строк одновременно
3. **История изменений** - не ведется лог изменений
